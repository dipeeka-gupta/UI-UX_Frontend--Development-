# DroneTV Frontend Task

A five-page DroneTV learning and aerial storytelling experience built with plain HTML5, CSS3 and vanilla JavaScript.

## Pages

- `index.html` - landing page
- `services.html` - production, training and consulting services
- `courses.html` - course catalogue
- `login.html` - client-side validated login demonstration
- `dashboard.html` - responsive learning dashboard

## Run locally

No build step or package installation is needed. Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

Images are currently loaded from Unsplash so the prototype remains lightweight. Replace those URLs with exported Figma assets inside `assets/images/` when the final design files are available. The supplied prompt did not include an actual Figma URL, so spacing, colors and imagery are an original DroneTV interpretation ready for visual tuning.
